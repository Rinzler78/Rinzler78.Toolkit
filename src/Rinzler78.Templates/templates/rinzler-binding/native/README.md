# Upstream baselines

This directory holds what the projection is generated *from*, committed so that a
change in the native library is a reviewable diff rather than a surprise:

- the upstream artefact's recorded identity — version, checksum, and the date it was
  taken;
- the mechanical description of its surface, as the platform's own tooling emits it;
- nothing generated by hand, and nothing edited after generation.

The projected C# surface is recorded separately, in the project's
`PublicAPI.Shipped.txt` and `PublicAPI.Unshipped.txt`. Two baselines, two questions:
this directory answers "what did upstream change", the API files answer "what does
that change to our consumers".
